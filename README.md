# Codicier

Codicier is a desktop app for authors who write books, stories, and essays.

## Status

The project is in the planning stage. The repo has no code yet.

## Goals

- The app runs on the computer as a native window. It does not use a web view.
- The app works offline. It sends no telemetry and needs no network connection.
- Each project is a folder of plain Markdown files. Other tools can read and edit the files.
- One workspace holds many projects: short stories, novellas, novels, and essays.
